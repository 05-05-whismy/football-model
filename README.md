Football Analytics

Веб-приложение для анализа футбольных матчей на основе статистики забитых и пропущенных голов.

Возможности

- Загрузка истории матчей из CSV.
- Оценка силы атаки и защиты команд.
- Расчёт вероятностей исходов 1X2.
- Расчёт вероятностей тоталов и обе забьют.
- Справедливые коэффициенты и ожидаемая доходность (EV).
- Исторический бэктест модели.

Формат CSV

Файл должен содержать столбцы:

"Date,HomeTeam,AwayTeam,HomeGoals,AwayGoals"

Приложение не гарантирует точность прогнозов. Расчёты основаны на исторических данных и не учитывают все факторы матча.
